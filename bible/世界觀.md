# 世界觀：《月下的歸途》（第四版）

> 本文件只描述這個世界本身。創作時參考的歷史細節、人物性格與動機，記錄在幕後底稿 `references/創作底稿_歷史素材.md`，不進入劇本。

## 一、核心命題

**誰掌握記錄，誰就掌握現實。**

全劇要問的是：**該記住什麼，又該放下什麼？**

| 層面 | 問題 |
|------|------|
| 國家 | 為了和平而遺忘罪行，還是為了正義而記住仇恨？ |
| 群體 | 誰有資格被記住？被遺忘的人，能否被找回來？ |
| 個人 | 抹去創傷，還是把失去整合進自己的故事？ |

## 二、世界的規則

### 名冊
- 寫入或抹去一個名字，世人的記憶就會跟著改變。
- 名冊同時是戶籍、稅冊和繼承登記。被抹去的人，在法律上也不存在。
- 名冊的力量一半來自祝福，一半來自人們的相信。人們越相信它，抹除就越徹底。

### 白鹽
- 北境灰岩郡的鹽山出產白鹽，它是**書寫名冊唯一的墨**。
- 貴族死後以白鹽保存遺體：肉身不腐，名字才能長存。
- 白鹽也是王國最大的稅源。北境因此被剝削，也因此握有籌碼。

### 祝福
- 少數人天生能以聲音觸動名冊，稱為「祝福」。祝福者能治癒、安撫，也能改變他人的記憶。
- **代價**：每用一次，就失去一部分自己的記憶。
- 教會徵召有祝福的少女，訓練成「聖歌者」；民間零星的祝福者（接生婆、說書人）則被視為異端。

### 活人的記憶
- 還有活人記得的事，抹除只能讓它模糊，因為倖存者會互相提醒。
- 等到記得的人都死了，只要名冊不寫，這件事就徹底消失。
- 所以名冊院最怕的不是叛軍，而是**還活著的證人**。

### 抹除簿
- 名冊院的戒律規定：每抹去一個名字，都要把原文抄進秘密的「抹除簿」，以備「衡」的最終審判。
- 抹除者的書庫，保存了所有被抹除的人。它藏在名冊院地下，只有歷任大書記長知道。

### 沉默之海與裂隙
- 被抹去的記憶不會消失，而是沉入包圍世界的「沉默之海」。
- 沉默之海滿溢時，記憶以扭曲的形式回來：變形的傳說、怪物，以及天空的裂隙。
- 裂隙通往這個世界「可能的未來」（見第九節）。

## 四、歷史

### 遠古：阿瑪拉
- 阿瑪拉的國王由書吏推選，萬民之名記於衡之書；人們相信名字被唸出的人就繼續存在。
- 最後一位書吏王抹去了太多名字：叛臣、敵國、災年的記錄。最後連人們怎麼耕種河岸都忘了。下一次大旱，阿瑪拉沒有撐過去。

### 聖名教會
- 倖存的書吏帶著衡之書的殘卷北上，在北境發現能書寫名冊的白鹽，創立聖名教會。

### 雙冠戰爭與聖女伊莎（約三百年前）
- 瓦倫與艾瑟打了一百多年的仗。
- 戰爭末期，一個叫伊莎的農家少女帶著祝福出現在戰場。人們以為她會帶領軍隊取勝。
- 她做的事出乎所有人意料：**她抹去了自己的名字，讓兩軍忘記了為誰而戰**。戰爭就這樣停了。
- 教會封她為聖女，宣稱名冊永遠保存著她的名字。
- **真相**：名冊裡早已沒有她。是百姓一代代傳唱的民謠，讓她活了下來。

## 七、宗教：聖名教會

- **教義**：世界由「衡」維持；名冊是衡的具現；被記住是恩典，被遺忘是懲罰。
- **組織**：
  - **名冊院**：書寫與抹除
  - **聖歌院**：培養聖歌者
  - **聖名騎士團**：審判與清剿
  - 名冊院與聖歌院暗中對立
- **聖女伊莎的兩種故事**：

| 版本 | 內容 |
|------|------|
| 教會的版本 | 名冊永遠保存著伊莎，她是名冊神聖的證明 |
| 民謠的版本 | 伊莎把自己的名字交給了唱歌的人 |
| 真相 | 名冊裡沒有她，民謠是對的。瑟伊恩想重演她的奇蹟，卻只記住了「遺忘」，沒記住「歌」 |

## 八、日常的質感

- **請假簿**：托爾保存的礦工請假簿上寫著「釀酒」「被蠍子螫」「替兄弟抹鹽」「老婆要生了」。
- **唸名日**：瓦倫的村莊每年在唸名日唸出死者的名字；艾瑟島國的移民只能低頭不語。
- **撐傘的宮廷**：王都的廷臣隨身帶傘，下雨天國王不出門，政務停擺。
- **北門的頭顱**：北境人每天經過都會看一眼。
- **民謠**：鄉間傳唱的伊莎之歌各地版本不同，拼起來就是她的最後之歌。

## 十、魔法的成長曲線

故事開始時，祝福稀少而昂貴。隨著沉默之海滿溢，祝福者越來越多、越來越強，民間出現無法控制的祝福者，教會的壟斷開始鬆動。**魔法變強，是世界生病的徵兆。**
