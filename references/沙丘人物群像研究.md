# 《沙丘》人物群像研究

> 依據法蘭克·赫伯特《沙丘》（1965）原著。只記錄群像設計的方法。

## 一、《沙丘》群像的六個設計原則

1. **每個人都是一個機構的節點**
   - 主要人物各自出身於帶有長遠議程的組織：亞崔迪家族、哈肯尼家族、帝國皇室、比·吉斯特姐妹會、宇航公會、宇聯公司、門泰特、蘇克醫生學院、弗瑞曼人
   - 人物的選擇受機構訓練與忠誠的限制，所以每個人都同時是「自己」和「機構的一部分」
2. **計中計**
   - 每一方都有層層嵌套的計畫，表面的計畫是為了掩護真正的計畫
   - 玩家（讀者）以為看懂了，下一層又翻出來
3. **神話是被種下的**
   - 比·吉斯特的「護使團」幾百年來在各星球散播預言，以便日後利用
   - 保羅成為救世主，是因為神話早已為他準備好位置
   - 赫伯特藉此警告：**小心英雄**，追隨者會把英雄變成災難
4. **資源是一切的中心**
   - 香料連接了經濟（宇航公會靠它導航）、宗教（弗瑞曼人的儀式）、預知能力和生態
   - 誰控制資源，誰就被資源控制
5. **書中之書**
   - 每章開頭引用作中人物寫下的文獻，多數出自伊如蘭公主的歷史著作
   - 這些引文提前透露結局的影子，也提醒讀者：我們讀到的是一個「被書寫過的」歷史
6. **長時間尺度**
   - 列特·凱恩斯父子規劃了三百年的生態改造
   - 比·吉斯特的育種計畫跨越九十代
   - 人物的一生，只是更長計畫中的一環

## 二、主要角色的功能

| 角色 | 機構 | 敘事功能 |
|------|------|----------|
| 保羅 | 亞崔迪家族／比·吉斯特育種計畫的產物 | 被神話選中的人；看見聖戰卻無法阻止。對「救世主」的批判 |
| 潔西卡 | 比·吉斯特 | 夾在姐妹會的命令與對家人的愛之間；違抗命令生下兒子，改變了一切 |
| 列托公爵 | 亞崔迪家族 | 正直的領主，明知是陷阱也得赴任；他的死逼主角成長 |
| 鄧肯·艾達荷 | 亞崔迪家族的劍士 | 極致的忠誠；最早與弗瑞曼人建立聯繫，為主家戰死 |
| 葛尼·哈萊克 | 亞崔迪家族的戰士 | 戰士兼詩人，帶著巴利斯琴；背負著被哈肯尼家族奪走的過去 |
| 杜菲·哈瓦特 | 門泰特（人形計算機） | 理性的極致，卻被誤導去懷疑潔西卡；後來被敵人利用 |
| 威靈頓·悅醫生 | 蘇克學院（受「帝國制約」不能害人） | **被脅迫的背叛者**：妻子被挾持，他打破了「不可能被打破」的制約，背叛主家，又暗中留下救命的安排 |
| 哈肯尼男爵 | 哈肯尼家族 | 赤裸的貪婪與殘暴；計中計的大師 |
| 沙達姆四世 | 帝國皇室 | 嫉妒受愛戴的公爵，暗中出兵 |
| 伊如蘭公主 | 帝國皇室／比·吉斯特 | 被政治婚姻犧牲的人，後來成為歷史的書寫者 |
| 莫希亞姆聖母 | 比·吉斯特 | 姐妹會的冷酷執行者；用「痛苦之盒」考驗保羅 |
| 列特·凱恩斯 | 帝國生態學家／弗瑞曼人 | 被派來監視，卻成了弗瑞曼人的領袖；為長期理想而死 |
| 斯第爾格 | 弗瑞曼人 | 從領袖變成信徒，象徵追隨者如何把英雄變成神 |
| 契妮 | 弗瑞曼人 | 主角的愛人；始終站在個人而不是神話那一邊 |

## 三、本作的取用

| 原則 | 本作做法 |
|------|----------|
| 每個人是機構的節點 | 八名主角各自出身於一個機構（聖歌院、名冊院騎士團、星環學院、金秤商會、北境礦工公會、王廷、自由傭兵團、未來），各帶著機構的訓練與忠誠衝突 |
| 計中計 | 聖歌院、名冊院、王后、商會各有表面與真正的計畫（見大綱「計中計」表） |
| 神話是被種下的 | 聖歌院三百年來在北境散播「南方的歌者將帶來解放」的預言。希雅一到北境就被奉為聖女轉世：這是她最大的危險 |
| 資源是一切的中心 | **白鹽**：北境出產的白鹽是書寫名冊的墨與保存遺體的材料（取自古埃及製作木乃伊用的泡鹼），也是王國鹽稅的來源。北境因此被剝削，也因此握有籌碼 |
| 書中之書 | 每章開頭引用作中文獻：瑪莉安的《歸途之歌》、名冊院的《抹除簿》、瑟伊恩的《書記長手札》、薇菈的《論沉默之海》、約拿的講道、伊莎的最後之歌 |
| 長時間尺度 | 聖歌院的三百年計畫、名冊院的三代記憶法則、艾絲特的月相觀測 |
| 被脅迫的背叛者 | 懺悔室神父安塞姆：妹妹被王后派挾持，在聖燭之夜為刺客打開大聖堂的門，事後卻暗中救下希雅 |
| 小心英雄 | 希雅必須拒絕成為救世主；第三幕「回聲之谷」就是她接受神話後的未來：一場以她為名的百年聖戰 |
