# 歷史研究：埃及、法國、英國，以及喬治·馬丁的方法

> 依據：通行的史學常識（Claude 既有知識整理，未做線上檢索）。每條史實後面附上「本作轉化」。

## 一、喬治·馬丁怎麼用歷史

- **骨架取自真實歷史**：
  - 《冰與火之歌》的主幹是英國玫瑰戰爭（蘭開斯特與約克）
  - 長城取自哈德良長城
  - 「血色婚禮」取材自蘇格蘭的「黑色晚宴」（1440）與格倫科大屠殺（1692）
- **人物取自真實原型**：瘋王伊里斯對應精神失常的英王亨利六世與法王查理六世；瑟曦帶有安茹的瑪格麗特的影子。
- **方法**：
  - 每章一個視角人物，每個人只知道自己看到的部分
  - 沒有人覺得自己是反派
  - 魔法稀少、昂貴，而且越來越強
  - 小人物承受大人物的戰爭
  - 歷史記載不可靠，傳說與真相互相矛盾
- **馬丁常引用的福克納名言**：唯一值得寫的，是「人心與自身的衝突」。

**本作轉化**：以三國歷史為骨架；八名主角是八個視角，各自只握有真相的一部分；加入敵方視角的「插曲」；魔法有代價；歷史記載本身就是劇情的戰場。

## 二、古埃及

| 史實 | 本作轉化 |
|------|----------|
| **上下埃及統一**：法老戴雙冠，統治兩個合一的國度 | 古國阿瑪拉的「雙冠王」；雙冠成為後世王權正統性的象徵 |
| **瑪阿特（Ma'at）**：宇宙的秩序、真理與平衡，法老的職責是維持瑪阿特、抵擋混亂（Isfet） | 「衡」的觀念：世界靠記錄維持平衡。教會自稱「持衡者」 |
| **尼羅河氾濫**：農業和曆法都依賴每年的洪水；神廟掌握糧倉 | 瑪河的氾濫與糧倉；誰控制糧食，誰就控制秩序 |
| **名字（ren）是靈魂的一部分**：死者的名字被唸出，就繼續存在；鑿去名字是「第二次死亡」 | **本作核心設定**：名字與記憶就是存在。教會的「名冊」能抹去一個人的名字，讓世人遺忘他 |
| **阿肯那頓的宗教改革**：獨尊阿頓，遷都阿瑪納；死後其名被鑿除，繼任者把他和其後幾位法老從王表中刪去 | 太陽王阿肯的改革與被抹除：第一次大規模「除名」，名冊的起源 |
| **哈特謝普蘇特**：女性法老，死後部分紀念碑被損毀 | 被抹去的女王，作為支線的歷史謎題 |
| **阿蒙祭司集團**：在底比斯坐擁巨富，第二十一王朝時大祭司實際統治上埃及 | 教會的「名冊院」坐大，與王權分庭抗禮 |
| **《亡靈書》與心臟秤量**：死者的心臟與瑪阿特的羽毛同秤 | 名冊院的「秤名儀式」：審判一個人是否值得被記住 |
| **戴爾麥地那工匠村**：拉美西斯三世在位第二十九年，因口糧遲發，工匠罷工，是史上最早有記載的罷工之一 | 支線「墓匠村的罷工」：慢熱日常中透出的國家財政危機 |
| **青銅時代崩潰（約公元前 1177 年）**：海上民族入侵、旱災、貿易網斷裂，東地中海文明連鎖崩潰 | 阿瑪拉亡於「海民之災」；也是諾亞所在未來的崩潰原型 |
| **羅塞塔石碑**：同一詔書以聖書體、世俗體和希臘文三種文字刻成，成為破譯古埃及文字的鑰匙 | 三語石碑：協力者歐文的破譯線，揭開名冊的原始用途 |
| **托勒密王朝**：希臘人統治埃及，卻披上法老的外衣 | 外來統治者借古國的正統性：瓦倫王室宣稱繼承「雙冠」 |

## 三、法國

| 史實 | 本作轉化 |
|------|----------|
| **百年戰爭（1337–1453）**：英王以母系血統主張法國王位，兩國斷續交戰一百一十多年 | 「雙冠戰爭」：瓦倫與艾瑟爭奪雙冠的百年戰爭 |
| **聖女貞德**：農家少女自稱聽見聖音，扭轉戰局，護送查理七世在蘭斯加冕；1430 年被俘，次年由教會法庭以異端罪判處火刑；1456 年平反，1920 年封聖 | **聖女伊莎**：被利用、被拋棄、被燒死，又在需要時被封聖。教會由此建立「聖歌者」徵召制度。希雅是她的後繼者 |
| **查理六世的瘋病**：一度深信自己是玻璃做的，怕被碰碎 | 「玻璃王」路德維克四世：國王瘋了，權力真空引發攝政之爭 |
| **聖殿騎士團覆滅（1307）**：腓力四世欠下鉅債，以異端罪名逮捕騎士團成員，大團長莫萊於 1314 年被處以火刑 | 「灰衣騎士修會」因王室債務被剿滅；其修道院荒廢，成為本作的據點 |
| **阿爾比十字軍（1209–1229）**：教會討伐卡特里派；傳說屠城時有人說「全殺了，上帝會認得自己人」；宗教裁判所由此發展 | 「卡爾斯村」的異端清剿，葛雷是執行者之一 |
| **亞維農教廷與天主教會大分裂**：教宗遷居亞維農（1309–1377），隨後一度出現兩到三位教宗 | 教會內部分裂：名冊院與聖歌院互相傾軋 |
| **聖巴托羅繆大屠殺（1572）**：新教領袖納瓦拉的亨利與王妹瑪格麗特的婚禮期間，巴黎爆發屠殺胡格諾派 | **「聖燭之夜」**：莉茲的政治婚禮變成屠殺之夜，也是第二幕的崩塌點 |
| **舊制度的財政危機**：貴族和教士免稅，鹽稅等重擔壓在第三等級身上，最終引爆 1789 年大革命 | 王國破產；北境的鹽稅與礦稅；商會是王室的債主 |
| **凡爾賽宮**：路易十四用宮廷禮儀把貴族圈養在身邊 | 王都聖瑟蘭的宮廷：貴族在禮儀中消耗，失去實權 |

## 四、英國

| 史實 | 本作轉化 |
|------|----------|
| **《末日審判書》（1086）**：諾曼征服後，威廉一世下令普查全國土地與人口，記錄全國資產 | 名冊的世俗用途：王國用它登記人口與稅賦。記錄就是權力 |
| **《大憲章》（1215）**：貴族迫使約翰王承認王權受法律限制 | 北境貴族與王室的「灰岩憲章」：被撕毀的承諾 |
| **黑死病（1348–）與勞工短缺**：人口銳減，勞工要求加薪，政府以法令凍結工資 | 「灰疫」：瘟疫後的勞工短缺與壓迫，是北境起義的遠因 |
| **農民起義（1381）**：瓦特·泰勒和傳教士約翰·鮑爾（「亞當耕地、夏娃紡紗時，誰是紳士？」）率眾進入倫敦；年輕的理查二世當面答應赦免與改革，事後反悔，鎮壓領袖 | **北境起義**：托爾參與其中。昂德魯公爵承諾赦免，事後背信屠殺。凱倫的父親死於這場鎮壓 |
| **玫瑰戰爭（1455–1487）**：亨利六世精神失常，約克公爵爭奪攝政權；塔中王子失蹤；理查三世在博斯沃思戰死，都鐸王朝建立 | 王后與王弟的攝政之爭；幼王的正統性疑雲 |
| **都鐸宣傳**：都鐸王朝把理查三世描繪成駝背暴君，莎士比亞的劇本加深了這個形象 | 瑪莉安的困境：宮廷詩人被雇來編寫「正史」 |
| **解散修道院（1536–1541）**：亨利八世與羅馬決裂，沒收修道院財產 | 艾瑟島國與教會決裂；瓦倫王室覬覦教會財產 |
| **圈地運動**：公地被圍起來，農民被迫離鄉進城 | 北境公地被商會圈占；也是「岔路迷宮」未來世界的根源 |
| **英國內戰與弒君（1649）**：查理一世被處決，克倫威爾執政，十一年後王政復辟 | 第三幕結局的歷史暗示：革命之後，舊秩序可能捲土重來 |

## 五、三者如何融合

1. **埃及提供「深層歷史」與核心概念**：名字、記憶、衡、抹除、被改寫的王表。這是世界的「地基」。
2. **法國提供「教會與王權」的衝突**：聖女、異端、騎士團、教廷分裂、財政破產、婚禮屠殺。
3. **英國提供「繼承戰爭與階級」**：瘋王、攝政、農民起義、背信的承諾、勝利者寫的歷史。
4. **共同主題**：誰掌握記錄，誰就掌握現實。這同時是個人的命題（你的人生故事由誰來寫），也是國家的命題（歷史由誰來寫）。這是本作「深度」的根。
