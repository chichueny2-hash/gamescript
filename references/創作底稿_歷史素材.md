# 創作底稿：歷史素材如何被拆解與重組

> 這是幕後文件，不進入劇本。世界觀與大綱裡不出現任何歷史原型；這裡記錄每個角色和事件是由哪些真實的細節、性格與動機拆解重組而成。
>
> **方法**（喬治·馬丁式）：不搬運歷史事件，只取三種東西：
> 1. **有畫面的細節**：一個動作、一件物品、一句話
> 2. **人物的性格與動機**：他為什麼這樣做
> 3. **處境的結構**：一個人被困在什麼樣的兩難裡
>
> 每個角色至少融合兩到三個來源，並換到全新的處境裡，讓人感覺得到真實的人性，卻對不上任何一段具體的歷史。

## 一、歷史素材庫（拆解後的原料）

### 有畫面的細節

| 細節 | 出處 | 有意思在哪 |
|------|------|------------|
| 國王相信自己是玻璃做的，在衣服裡縫進鐵條，怕被碰碎 | 法王查理六世 | 權力最高的人，最怕自己破碎 |
| 宴席上端出一顆黑牛頭，賓客隨即被拖出去斬首，年幼的國王在旁哭求 | 蘇格蘭「黑色晚宴」（1440） | 一道菜就是死亡信號；孩子被迫成為見證人 |
| 新娘在婚禮上拒絕說「我願意」，她的哥哥按下她的頭，讓她點頭 | 瓦盧瓦的瑪格麗特（1572） | 一個人的同意可以被別人的手代替 |
| 財政大臣為國王辦了一場比王宮還奢華的宴會，三週後被捕 | 富凱與沃子爵城堡（1661） | 炫耀就是自掘墳墓 |
| 天文學家在決鬥中被削掉鼻子，起因是爭論一道數學公式；他終身戴著金屬假鼻 | 第谷·布拉赫 | 為了「對」，可以付出荒謬的代價 |
| 工匠缺勤記錄上寫著理由：「釀酒」「被蠍子螫」「替兄弟做防腐」「妻子在流血」 | 埃及戴爾麥地那工匠村 | 四千年前的請假條，和今天一模一樣 |
| 被處決的叛亂者頭顱掛在城門上數十年 | 克倫威爾的頭顱（1661–1685） | 死人比活人在位更久 |
| 倫敦大火中，日記作家把他的帕馬森乳酪和葡萄酒埋進花園 | 佩皮斯日記（1666 倫敦大火） | 末日裡，人在乎的往往是很小的東西 |
| 謀反者把密信藏在啤酒桶的塞子裡傳遞，卻全被情報頭子截讀 | 巴賓頓陰謀（1586） | 自以為隱秘的通道，其實是陷阱 |
| 受審的文盲少女被問「妳是否在神的恩典中」，回答「若不在，願神接納我；若在，願神保守我」 | 貞德受審（1431） | 被逼入絕境的人，說出比審判者更聰明的話 |
| 王后在宮廷花園裡蓋了一座假的農村，在裡面扮演擠奶女工 | 瑪麗·安東尼的小村莊 | 逃避的方式，是假裝成另一個人 |
| 為了讓被處決的王后少受苦，國王特地從外國請來最好的劍手 | 安妮·博林（1536） | 一種殘忍的仁慈 |
| 寡居的王后寫信給敵國國王，請他送一個兒子來娶她，因為她「絕不嫁給一個僕人」；那位王子死在半路 | 安克蘇娜蒙的書信 | 被困的女人向敵人求援 |
| 法官在審理叛亂案期間，被發現與被告的女眷一起宴飲，法官本人遭到懲處 | 拉美西斯三世的後宮陰謀 | 審判者本身也在腐爛 |
| 兩個城區的市長互相指控對方監守自盜，盜墓案成了政治鬥爭 | 埃及盜墓案莎草紙 | 正義被當成打擊對手的武器 |
| 國王在戰役中僵持不下，回國後把「大捷」刻滿全國的神廟 | 卡迭石之戰 | 宣傳比戰場更重要 |

### 人物的性格與動機

| 人物 | 出處 | 可取用的動機或性格 |
|------|------|--------------------|
| 國王把最好的朋友任命為大主教，以為能控制教會；朋友卻成了教會最頑強的捍衛者。國王一句氣話「難道沒人能替我除掉這個麻煩的教士？」讓四名騎士殺了他，國王事後赤腳懺悔、讓修士鞭打自己 | 亨利二世與貝克特 | **友情被良知背叛**；**一句氣話殺人**；**誰該為「暗示」負責？** |
| 十四歲的國王在叛軍首領被殺後，獨自策馬上前喊「我是你們的國王，跟我來」，平息了叛軍；事後全部反悔 | 理查二世（1381） | **少年的勇氣與日後的背信，出自同一個人** |
| 座右銘是「忠誠縛我」，忠於兄長二十年，兄長死後卻奪了姪子的王位 | 理查三世 | **極致的忠誠如何翻轉** |
| 擁立又廢黜國王的權臣 | 「造王者」沃里克伯爵 | 以為自己能控制國王的人 |
| 十三歲生下獨子，此後一生都在為讓兒子登上王位而布局 | 瑪格麗特·博福特 | **母親的執念**，虔誠與冷酷並存 |
| 外國出身的王太后，被後世當成一切屠殺的元兇 | 凱瑟琳·德·梅迪奇 | **被歸咎的外人**；為了保住兒子們什麼都做 |
| 「給我任何一個人親手寫的六行字，我就能找到絞死他的理由」 | 黎塞留（傳） | 國家理性；冷靜的權力 |
| 歷經王朝、革命、帝國、復辟，每次都站在贏的一邊 | 塔列朗 | 生存者的道德 |
| 為了王位三度改宗，「巴黎值得一場彌撒」 | 亨利四世 | 務實到沒有信仰 |
| 鐵匠之子，一路爬到國王身邊最有權力的人，最後被他服侍的國王處決 | 湯瑪斯·克倫威爾 | 出身卑微者的上升與墜落 |
| 陪伴聖女作戰的貴族英雄，後來成了連環殺手 | 吉爾·德·雷 | 英雄可以墮落成怪物 |
| 女法老在雕像上戴假鬍鬚 | 哈特謝普蘇特 | 為了被承認，必須扮演另一種人 |

## 二、重組表：每個角色由什麼組成

| 本作角色 | 融合的素材 | 換到什麼新處境 |
|----------|------------|----------------|
| **昂德魯公爵** | 理查二世的少年勇氣 ＋ 亨利二世的氣話與懺悔 ＋ 理查三世的「忠誠縛我」 | 十九歲獨自騎進叛軍營地，平息了起義；幾天後一句氣話讓騎士屠了北境；此後赤腳懺悔，卻始終不肯取下城門上的頭顱，說「我要記得」 |
| **大書記長瑟伊恩** | 貝克特（國王的朋友變成教會的捍衛者）＋ 黎塞留的六行字 ＋ 塔列朗的生存術 | 老國王的兒時好友，被派去控制名冊院，卻成了名冊院最堅定的守護者；他不恨任何人，只計算 |
| **王后伊莎蓓爾** | 凱瑟琳·德·梅迪奇的外人處境 ＋ 瑪格麗特·博福特的母親執念 ＋ 瑪麗·安東尼的假農村 ＋ 安克蘇娜蒙寫給敵國的信 | 在宮廷花園裡蓋了一座故鄉的小村，只在那裡說母語；暗中寫信給艾瑟島國女王求援 |
| **紙王路德維克** | 查理六世的玻璃妄想（變形為「紙」） | 深信自己是紙做的，怕水；宮廷裡隨時有人撐傘；每個時辰要人唸一次他的名字 |
| **會長奧古斯特** | 富凱的奢華宴會 ＋ 亨利四世的改宗 ＋ 塔列朗 | 改過三次信仰；在金秤之城辦了一場比王宮還奢華的宴會，那是他倒台的開始 |
| **院長瑪格達** | 瑪格麗特·博福特的一生布局（變形：她已不記得布局的初衷） | 年輕時是聖歌者，記憶早已用盡；她靠一本筆記本執行自己當年的計畫，卻忘了自己為什麼開始 |
| **騎士長奧斯溫** | 安妮·博林的劍手（殘忍的仁慈） | 處決北境叛軍時，他特地要了最鋒利的劍，好讓他們少受苦。凱倫無法原諒這份仁慈 |
| **神父安塞姆** | 巴賓頓陰謀的啤酒桶密信 ＋ 被脅迫者 | 在懺悔室裡傳遞密信，自以為隱秘，其實每封都被王后的人讀過 |
| **凱倫** | 鐵匠之子克倫威爾的上升渴望 ＋ 目睹理查二世式少年英雄的孩子 | 七歲時看見年輕的公爵獨自騎進叛軍營地，從此想當騎士；不知道正是這位公爵的一句話害死了父親 |
| **希雅** | 貞德受審時的機智回答 ＋ 哈特謝普蘇特的假鬍鬚（扮演被要求的角色） | 平時溫順微笑，被逼問時卻說出讓審問者啞口無言的話；她把自己的名字一針一針縫進袖口，怕忘記 |
| **薇菈** | 第谷的金屬鼻子 | 為了一道公式和同事決鬥，被削掉鼻尖，從此戴銀鼻；寧可對，也不要被喜歡 |
| **葛雷** | 殺死貝克特的四名騎士（執行「暗示」的人） | 當年王后的近衛；把一句「我不要任何人記得今天」當成命令 |
| **莉茲** | 瓦盧瓦的瑪格麗特被按頭點頭 ＋ 商人之女的算計 | 議價時精明無比，選衣服卻選不出來；婚禮上她不肯點頭，父親的手按下了她的頭 |
| **托爾** | 戴爾麥地那的缺勤記錄 ＋ 克倫威爾的頭顱 ＋ 約翰·鮑爾的歌謠（變形） | 每天早上向城門上的頭顱打招呼；手上有一本礦工請假簿；會唱「鹽山開口時，誰是老爺？」 |
| **瑪莉安** | 卡迭石的宣傳 ＋ 佩皮斯埋乳酪 | 擅長把僵局寫成大捷；聖燭之夜大火中，她把手稿和一輪乳酪埋進花園 |

## 三、事件的重組

| 本作事件 | 融合的素材 | 改造 |
|----------|------------|------|
| **聖女伊莎** | 貞德（少女扭轉戰局）＋ 哈特謝普蘇特與阿肯那頓（被抹去）＋ 民謠傳唱 | 她不是被燒死的殉道者。她在百年戰爭末期用祝福抹去了自己的名字，讓兩軍忘記為誰而戰，戰爭因此停下。教會說名冊保存了她；真相是名冊裡早已沒有她，是百姓的歌讓她活了下來 |
| **卡爾斯村** | 黑色晚宴的「見證者」主題 ＋ 貝克特騎士的「暗示」 | 國王第一次發瘋就在卡爾斯附近的夏獵。王后說了一句「我不要任何人記得今天」，近衛們燒了整個村子 |
| **北境屠殺** | 理查二世的少年勇氣 ＋ 亨利二世的氣話 | 年輕的公爵平息了起義，幾天後在議事時怒吼「難道沒人能讓那些鹽蟲閉嘴？」騎士們連夜出發 |
| **聖燭之夜** | 黑色晚宴的黑牛頭 ＋ 瑪格麗特的婚禮 ＋ 鄰居相殺 | 婚宴上端出一盤白鹽，就是動手的信號 |
| **灰衣修會覆滅** | 富凱的宴會 | 修道院長為國王辦了一場太奢華的宴會，國王回程時就決定沒收修會 |
| **紙王** | 查理六世 | 玻璃變成紙，因為這個世界裡最脆弱的是記錄 |
